# PHYSICA — 物理を遊ぶ実験世界

**[ゲームを開く](https://player13579.github.io/physica-world/)**

ブラウザ内で動く、2D・3Dの物理サンドボックスです。力学・流体・熱・光の4つの実験室を用意しています。サーバーへのデータ送信、アカウント登録、APIキーは不要です。

## 2Dと3Dを用意した理由

2Dでは断面全体を見渡せるため、流れ、温度分布、光の経路が物体の裏に隠れません。編集が簡単で計算負荷も小さいモードです。3Dでは奥行きのある配置、立体の衝突、体積内の熱伝導を視点を回しながら観察できます。3Dは見た目だけの立体化ではなく、XYZ方向で計算します。各実験室・次元は独立しており、切替時は新しい実験を開始します。

## 遊び方

- 実験室と次元を選びます。2Dにはドミノ、二重振り子、プリズムなどの初期シーンがあります。
- 2Dではツールを選び、クリック・ドラッグで物体、染料、熱源、鏡などを配置・操作します。
- 3Dでは「視点」でドラッグして回転、ホイール・ピンチでズームします。配置ツールを選び、高さを設定してクリックすると、その水平面に配置します。
- 3Dの「押す」は物体への上向きの力積、「移動」はクリック位置に最も近い光学物体を移す操作です。3Dの鏡はX方向に法線を持つ固定方向の平面です。
- 一時停止、1フレーム送り、0.25〜2倍速を利用できます。Spaceで一時停止／再生、Rで現在の実験をリセットします。
- ミニチャレンジでは、ボールの到着、インク濃度、平均温度、反射回数などの実際の状態を判定します。

## 計算している現象と限界

| 分野 | 2D | 3D | 主な省略 |
|---|---|---|---|
| 力学 | Matter.js剛体、重力、衝突、摩擦、反発、拘束 | Cannon-es剛体、6面の容器、重力、衝突 | 変形、破壊、精密な空気抵抗 |
| 流体 | 100×65格子の移流、粘性、反復圧力投影、固体境界の近似 | 最大600粒子、密度カーネル・対称圧力・粘性・容器衝突 | 厳密な非圧縮性、乱流、水面再構成、多相流 |
| 熱 | 100×65格子の熱方程式 | 18×12×12格子の6近傍熱拡散 | 対流、放射、相変化、熱機関 |
| 光 | 反射、スネル屈折、全反射、プリズムの簡易色分散 | 球面での3Dスネル屈折、有限平面鏡での反射・全反射 | 干渉、回折、偏光、波動、フレネル強度分岐 |

教育・遊び向けの有限解像度の近似モデルです。流体と熱の時間・係数は見やすさを優先した相対値で、実在物質の校正済み計算には使えません。初期温度は20°C、冷却源は0°Cです。熱源・冷却源は外部からエネルギーを出し入れする温度固定境界です。熱と流体など、別実験室間の連成は扱いません。

2Dの力学は80座標単位を1mに対応させています。エネルギー表示は並進運動＋重力位置エネルギーの概算で、回転エネルギーを含みません。3Dの熱は室温との差が2°C以下のセルを非表示にして内部を見やすくしています。体積の描画は半透明ボクセルで、光学物体の重なりによる複雑な媒質構成は対象外です。

## 開発と公開

Node.js 22.13以上。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

React + Viteで静的ファイルを`docs/`へ生成します。相対アセットパスなのでGitHub Pagesのプロジェクト配下で動きます。GitHub Pagesの公開元は`Codex-honoo`ブランチの`/docs`です。`.nojekyll`はビルド後に自動生成します。公開済みビルドもソースと一緒にコミットします。

`src/engines/`はDOMに依存しない計算、`src/render/`はCanvas 2D / Three.js描画、`app/page.jsx`は操作画面です。描画する形状は衝突・温度・光線の計算状態そのものに対応します。画像生成資産や外部CDNは使っていません。

## 検証

- Nodeの22テスト：重力と境界、素材差、削除と拘束、2D流体移流、熱拡散、3D深さ方向の熱移動、スネルの法則、屈折率1での直進、全反射、3D鏡反射、粒子障害物、上限など。
- 静的画面のサーバーレンダリング、Vite本番ビルド、制作したソースのlint（生成されたUIライブラリの未使用コンポーネントは対象外）。
- ブラウザ操作・スクリーンショットによる確認は未実施。ブラウザ接続が応答しませんでした。
- 任意のWebMCPツール2件を機能検出で登録します。対応する検証コンテキストが利用できず、実機登録は未検証です。

数値モデルの参考：[Matter.js](https://brm.io/matter-js/)、[Cannon-es](https://github.com/pmndrs/cannon-es)、[Stable Fluids（Jos Stam）](https://www.dgp.toronto.edu/public_user/stam/reality/Research/pdf/ns.pdf)。
