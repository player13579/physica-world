# PHYSICA — 自然の世界

公開: **https://player13579.github.io/physica-world/**

川が流れ、草木が燃え、太陽の熱で地面が温まる、32 m四方の自然のサンドボックスです。旧版の独立した物理実験室を、同じ地形上で水・燃焼・放射熱・日射・風・雨が作用する世界に置き換えました。

## 遊び方

- 「見わたす」: 1本指で3D回転。2Dでは平行移動。2本指で移動・拡大。
- 「水を注ぐ」: 水を追加。傾斜を下り、熱も流れに運ばれます。
- 「火をつける」: 地面を着火温度まで加熱。草木の燃料を消費し、放射熱が周囲を温めます。水や雨で抑制・消火できます。
- 「土を盛る」「地面を掘る」: 川をせき止めたり、溝や池を作ったりできます。
- 「緑を増やす」: 燃料となる草木を植え直します。
- 「雨を降らす」: 局所的に水を与えて濡らします。設定では世界全体の降雨を調整できます。
- 設定: 時刻、日差し、風速・風向、雨、水源。温度ボタンで地表・水温を色に変換します。
- 一時停止、0.25/1/4倍速、リセット。キーボードはSpaceで停止、1–7で道具、Escapeで視点操作。

タブレットの縦横表示とセーフエリアに対応。小画面では道具列を横にスクロールできます。外部API、アカウント、サーバー保存は不要です。ページを開き直すと世界を作り直します。

## 2Dと3Dを搭載した理由

2Dは真上から流路や延焼範囲を見渡し、狙った地面を編集するのに適しています。3Dは斜面・水深・樹木・太陽の影を空間として観察できます。両者は同じ地形と全シミュレーション配列を使い、切り替えても水量・温度・進行は維持します。2Dは独立した側面ソルバーではなく正射影の俯瞰モードです。

## 再現している現象

| 現象 | 計算と描画 |
|---|---|
| 川・池 | 80×80格子の水深と持続する面流量。重力による水面の高低差、抵抗、流出量制限で非負の水量を保存。水源・雨・流出・蒸発・手動追加を別に記録。 |
| 熱を運ぶ水 | 実際に隣へ移動した水量と同じ流束で水温を輸送。地面と水の顕熱交換は両者の平衡を越えないよう制限。 |
| 燃焼・熱放射 | 温度、乾燥度、燃料量で燃焼速度を計算。消費燃料×18 MJ/kgの化学エネルギーから局所加熱と距離・遮蔽に応じた放射加熱を配分。周囲が発火温度に達すると延焼。 |
| 消火・蒸発 | 濡れと滞留水による燃焼抑制、冷却、供給エネルギーで制限した蒸発潜熱。単なる炎の表示切替ではありません。 |
| 日射・木陰 | 共通の太陽方向から地形の傾斜・地形の遮蔽を計算。描画する樹冠の位置・大きさ・遮光率も熱計算へ渡し、焼失後は日射が戻ります。雨天の日射減衰も共通化。 |
| 自然の表示 | Three.jsの空、大気散乱、地形・樹木の影、水面の屈折・Fresnel反射、流れに応じた泡。炎と煙、局所照明は実際の燃焼状態・速度から描画。煙は浮力・風で移流する表示粒子。 |

火の道具による着火エネルギーも別に計上し、指を置くたび無制限に温度を加算する方式を避けています。大きい時間刻みは最大0.04秒に分割します。

## 限界

現実の自然をすべて解くものではなく、相互作用を遊べる数値近似です。水は地形上の深さで表すため、空中の滝・飛沫・砕波・水中の三次元渦は解きません。煙・細かな波・草木の揺れは物理状態に応じた描画で、空気全体のNavier–Stokesや木の弾性体計算ではありません。燃焼化学、酸素濃度、雲の生成、生態系、完全な光の多重散乱は対象外です。火の照明と樹冠の熱遮蔽も近似です。

影・屈折・反射を優先し、画素比上限2、太陽の影2048px、主要な火の影512pxを使用します。タブレットの機種によって速度は変わります。タブレット実機・ブラウザGPUでの操作検証は未実施です。

## 開発と検証

```sh
npm install
npm run dev
npm test
npm run lint
node scripts/verify-nature.mjs
npm run build
```

Vite + React + Three.js。ビルド先は`docs/`、相対パス、`.nojekyll`。GitHub Pagesは`Codex-honoo`ブランチの`/docs`を公開します。旧実験室エンジンとその回帰テストはソースに残っていますが、現在の入口では読み込みません。

数値検証は水収支、流れの方向、地形による流路変更、放射による加熱・発火、燃料消費、水による消火、熱移流、降雨、太陽・地形・樹冠の影、長時間の有限性を含みます。Three.jsのCPU検証では木の寸法、地層の壁が外周内に留まること、燃えた/浸水した草の非表示、資源解放を確認します。SSR・ビルドはブラウザ描画の検証とは別です。

物理近似の一次資料: [USGSの浅水流モデル](https://www.usgs.gov/publications/finite-volume-model-two-dimensional-shallow-environmental-flow)、[NISTの火災ダイナミクス](https://www.nist.gov/el/fire-research-division-73300/firegov-fire-service/fire-dynamics)、[NISTの水による消火](https://www.nist.gov/publications/fire-fighting-properties-nistir-6191)、[NASAの地球のエネルギー収支](https://science.nasa.gov/earth/earth-observatory/climate-and-earths-energy-budget/)。実装の詳細と表示の対応は`audits/`に記録しています。
